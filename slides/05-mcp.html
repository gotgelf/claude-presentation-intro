MCP — Connect Your Tools

Model Context Protocol lets Claude work with external services directly.

Figma

Read designs, inspect components, extract styles. Build UI directly from Figma mocks without manual spec translation.

Shortcut

Read stories, create tasks, update status. Link code changes to tickets and automate project tracking.

Slack

Read channels, search messages, send updates. Stay connected with your team without leaving the terminal.

# Add an MCP server
$ claude mcp add figma \
  --transport http \
  https://figma.com/mcp

$ claude mcp add shortcut \
  --transport http \
  https://shortcut.com/mcp

# Or configure in .mcp.json
{
  "mcpServers": {
    "slack": {
      "type": "http",
      "url": "https://slack.com/mcp"
    }
  }
}
