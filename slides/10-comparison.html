Side-by-side comparison — triggers, config, and sweet spots.

CLAUDE.md Auto-loaded at session start; survives /compact ./CLAUDE.md · .claude/rules/ Team conventions, build commands, architectural decisions Static

Agent Teams Self-coordinating via shared task list & direct messages Env: CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS=1 Cross-layer changes, competing hypotheses, multi-angle review AI-driven (experimental)
Decision rule
Start with CLAUDE.md. Add hooks for guardrails. Reach for skills when you repeat a workflow. Use MCP for external data. Escalate to sub-agents for parallelism, and teams only for true multi-track coordination. Package as a plugin when you need to share.
