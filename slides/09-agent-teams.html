How It Differs

Unlike subagents, teammates message each other directly, share a task list, and self-coordinate. Each is a full independent Claude session.

Best For

Parallel code review, competing hypotheses debugging, cross-layer changes (frontend + backend + tests), research from multiple angles.

Good to Know

Experimental feature. Higher token cost (each teammate has own context). Start with 3-5 teammates. Avoid same-file edits across teammates.
