Deep Dive

Building Custom Skills

Teach Claude new capabilities with a single markdown file.

SKILL.md

Entry point for every skill. YAML frontmatter controls behavior, markdown body has the instructions Claude follows.

Where They Live

Project: .claude/skills/ (shared via git). Personal: ~/.claude/skills/ (all your projects).

Key Options

disable-model-invocation for manual-only. context: fork for subagent. paths to scope to files. allowed-tools to restrict access.

# .claude/skills/deploy/SKILL.md
---
name: deploy
description: Deploy to staging
disable-model-invocation: true
allowed-tools: Bash(npm *)
---

Deploy $ARGUMENTS to staging:

1. Run the test suite
2. Build the application
3. Push to deployment target
4. Verify health checks pass
