Useful Commands

A quick reference to get you started.

/initBootstrap CLAUDE.md — first thing in any new project
/sandboxToggle sandbox mode
/configView and edit Claude Code settings and permissions
/code-reviewDeep code review of a pull request
/compactCompress context when conversation gets long
/btwQuick side-task without losing current context
/resumeResume a previous conversation where you left off
/statsView session statistics and token usage
! commandRun shell inline (e.g. ! make test)
/insightsAnalyze sessions, interaction patterns, and friction points
